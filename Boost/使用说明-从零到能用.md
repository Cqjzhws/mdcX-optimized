# mdcX Boost 自研加速 — 从零到能用（巨魔 / TrollFools）

这套东西分两个文件，各干各的活：

| 文件 | 干什么 | 怎么装 |
|---|---|---|
| `Configurator/mdcXBoost配置器-1.0.ipa` | **写配置**：选档位、开关、后台保活 | 巨魔/TrollStore 直接装 |
| `out/mdcxboost.dylib` | **真正加速**：注入到进程后 hook 动画/响应/后台 | TrollFools 注入到目标 App |

为什么分开：加速的本体是运行时 hook，必须注进目标进程才生效；而配置总要有个界面来写。
配置器写出的配置放在 `/var/mobile/Library/Preferences/com.mdcx.boost.plist`，
dylib 注入后读这份配置，改档位会发通知让它**即时生效，不用重新注入**。

---

## 第 1 步：装配置器（1 分钟）

1. 把 `mdcXBoost配置器-1.0.ipa` 传到手机（AirDrop / 文件 App / 本地服务器都行）。
2. 用 **TrollStore 或巨魔** 安装（图标是金闪电，名字「mdcX Boost」）。
   - 注意：不要用普通侧载（AltStore/Sideloadly），那样写不了共享配置目录。
3. 打开它，会看到界面：
   - **总开关**：启用/关闭加速
   - **加速档位**：安全 8× / 均衡 24× / 极速 50×
   - **功能开关**：转场启动加速、交互响应、安全熔断
   - **后台保活**：开关 + 强度（音频 / +任务 / 全策略）
   - 右上角「恢复默认」

先选好档位（建议**均衡 24×**起步），配置就写好了。这一步不需要重启。

## 第 2 步：用 TrollFools 注入 dylib（关键）

加速真正生效靠这一步。把 `mdcxboost.dylib` 注入到你想加速的进程：

1. 打开 **TrollFools**。
2. 选目标 App → 注入 → 选 `mdcxboost.dylib`。
3. 推荐注入顺序（按需求取舍）：
   - **SpringBoard**（`com.apple.springboard`）：系统界面、控制中心、App 切换动画 —— 效果最明显
   - **你想加速的 App**：微信、Safari、抖音、游戏等，逐个注入
   - 注意：`com.apple.UIKitCore` 是系统库，TrollFools 一般不会让它单独选，跳过即可
4. 注入后 **重启对应 App**（SpringBoard 注入会 respring 或重启桌面）。

> 注入是 TrollFools 帮你把 dylib 塞进 App 的 Mach-O 并重签名，本机 PC 做不了，只能在你手机上操作。

## 第 3 步：验证生效

**看日志**（macOS 控制台，或巨魔日志工具，过滤 `mdcXBoost`）：
```
[mdcXBoost] mdcX Boost v1.0.0 launching in process: com.apple.springboard
[mdcXBoost] animation hooks installed (UIView x5, CAAnimation, CATransaction)
[mdcXBoost] interaction hooks installed (UIScrollView, UIGestureRecognizer)
[mdcXBoost] background keeper installed
[mdcXBoost] safety net installed (reload + circuit breaker)
[mdcXBoost] READY | profile=1 mult=24.0 floor=0.012 protected=0 circuit=1
```
看到 `READY` 就是生效了。在配置器里改档位，应看到：
```
[mdcXBoost] reload notification received, config refreshed
```

**看体感**：
- 控制中心上拉、App 开关、页面 push/pop 明显更快，但不"闪现"（有帧保底）
- 列表滚动更快停住、长按图标弹出更快
- App 切后台停留更久

## 档位说明

| 档位 | 倍率 | 适用 |
|---|---|---|
| 安全 | 8× | 日常、第三方重 App，最稳 |
| 均衡 | 24× | 推荐，速度与稳定兼顾 |
| 极速 | 50× | 全速，配合保护名单+熔断兜底 |

**保护名单**：微信、企业微信、Safari 命中后自动降到 8×，避免高倍率闪退——这是内置的保护，不用管。
**安全熔断**：某 App 短时间连崩，自动降安全档，防止无限闪退。

## 回滚 / 出问题怎么办

- **关加速**：配置器里关总开关，已注入进程即时停手，不用重启。
- **降档**：配置器切「安全」。
- **彻底移除**：TrollFools 里把注入的 dylib 移除，重启设备，回到原生。
- 全程**不改任何系统文件**，回滚零残留。

## 关于「带加速页的完整 mdcX 主 App」

我改好的 mdcX 源码已 push 到 GitHub（`main` 和 `boost/mdcx-1.0.0` 分支都有），
里面有 SwiftUI 写的「加速」tab。但：
- 本机 Windows 没 Xcode，编不了 SwiftUI 主 App；
- GitHub Actions 云端编译这次被平台取消了（job 启动 1 秒就被 cancel，非代码问题）。

所以暂时用不了那个带 tab 的版本。**当前这套「配置器 + dylib」功能完全等价**——
配置器干的就是那个 tab 的活，加速效果一模一样。等云端编译恢复，或你有 Mac/Xcode，
随时能出完整主 App IPA。
